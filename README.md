# Песочница + сюжет

Игра на Python и pygame: сюжетный режим про завод, двух питомцев (Бублик и Мурка)
и свободная песочница с песком, водой, кислотой, нефтью, порохом, огнём и металлом.

## Управление
- Выбери материал внизу и рисуй мышкой или пальцем.
- «Кисть» меняет размер кисти, «Ластик» стирает, «Очистить» сбрасывает поле.
- «Пёс» и «Кот» — кликни по полю, чтобы поставить питомца (до 4 каждого).
- Esc — назад в меню.

## Запуск на компьютере
```bash
pip install -r requirements.txt
python main.py
```

## Сборка APK через GitHub Actions (без своего Android SDK)
1. Создай репозиторий на GitHub и залей все файлы (включая папку `.github`).
2. Открой вкладку **Actions** → **Build APK** → запусти вручную (**Run workflow**),
   либо просто сделай `push` в ветку `main`.
3. Первая сборка занимает около часа. Когда она закончится, в разделе **Artifacts**
   появится архив `sandbox-apk` с готовым APK.
4. Скачай APK на телефон и установи (разреши установку из неизвестных источников).

Сборка локально (только Linux): `pip install buildozer cython==0.29.33 && buildozer android debug`.

## Структура
- `main.py` — меню, интерфейс, ввод, главный цикл
- `sim.py` — клеточная симуляция веществ
- `entities.py` — питомцы: ходьба, падение, бегство от огня
- `story.py` — главы, диалоги и задания сюжета
- `assets/` — картинки питомцев и шрифт
- `buildozer.spec` — настройки сборки APK
- `.github/workflows/build-apk.yml` — автосборка APK в облаке GitHub

## Важно
- Все вещества в игре выдуманные и служат только игровой механике.
- Картинки питомцев (`assets/dog.png`, `assets/cat.png`) — твои. Если репозиторий публичный,
  убедись, что у тебя есть права на эти фото.
